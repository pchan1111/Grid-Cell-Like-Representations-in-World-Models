# Emergence of Grid-Cell-Like Representations in World Models for Reinforcement Learning

This is the official implementation of "Emergence of Grid-Cell-Like Representations in World Models for Reinforcement Learning".

## Requirements

- Python 3.10
- Ubuntu 22.04.5 LTS
- CUDA Version: 12.2

## Installation

```bash
pip install -r requirements.txt
```

## Training

```bash
chmod +x train.sh
./train.sh
```
